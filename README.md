# Emotion Prediction from Text

Master's thesis project focused on predicting user emotional states from textual records using NLP and transformer models.

## 🔗 Links
* **Thesis:** [View on LPNU Repository](https://ena.lpnu.ua/items/327ce430-ec29-4aea-9cfc-fa7d8dde1888)
* **Publication:** [Ukrainian Journal of Information Technology (Vol. 8, No. 1)](https://science.lpnu.ua/ujit/all-volumes-and-issues/volume-8-number-1/prediction-individuals-emotional-state-based-textual)

## 🛠️ Tech Stack
* **ML & NLP:** PyTorch, Transformers, NLTK, Datasets
* **Backend API:** FastAPI, Uvicorn, Pydantic
* **Background Tasks:** Celery, Redis
* **Bot Integration:** Aiogram (Telegram)
* **Data Processing:** Pandas, NumPy, BeautifulSoup4
* **Translation & Lang:** DeepL, Langdetect
* **Visualization:** Matplotlib
